# Dataform Best Practices

Google has some [best practices](https://cloud.google.com/dataform/docs/best-practices) for how to configure Dataform, but it can be a bit hard to see how they play together with software engineering best practices like [Minimum Viable CD](https://minimumcd.org/).

This repo is based on Google's docs, 4+ years of working in Dataform, and a variety of software engineering best practices.

# Usage

1. Fork this repo
2. [Setup a new Dataform repo and connect to Github](https://cloud.google.com/dataform/docs/connect-repository)
3. Give the Dataform service account `BigQuery Data Editor` or `BigQuery Data Viewer` in the projects you intend to use [as appropriate](https://cloud.google.com/dataform/docs/quickstart-create-workflow#grant-access-bigquery)
